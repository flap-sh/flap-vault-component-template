# 0.1.40-next.0 — complete long-text copying

[简体中文](0.1.40-next.0.zh-CN.md)

Prepared for npm `next`; not yet published. Stable `latest` remains `0.1.37`.

- Raise the shared `CopyButton` limit from 4,096 to 1,048,576 UTF-16 code units (`value.length`), for complete `skills.md` and other long Markdown.
- Keep one component for Vault UI and Mini App v2, with the same import and props. Spaces and line breaks are retained. Emoji may use more than one code unit.
- Retain trusted user clicks, invalid-value checks, pending deduplication, clipboard failure reporting and the fullscreen selection fallback. No imperative clipboard API or clipboard read is exposed to artifacts.
- Verify actual clipboard round trips for long Unicode Markdown and the exact upper bound in both providers, plus the real browser selection fallback and consumer runtime checks.

Flap hosts and Workbench must pin this exact runtime, update Workbench's validation identity and deploy together. App developers update the official `feat/mini-app-v2` template and rerun check, E2E, package and verification. Existing artifacts remain compatible. No dependencies or package protocol changes are added. See [CopyButton](../copy-button.md).
