# Vault Runtime 0.1.48

[PR #68](https://github.com/flap-sh/flap-vault-component-template/pull/68)
adds scoped ERC-20 approvals for standalone Mini Apps. The manifest can
declare a fixed token allowlist or `["*"]` for runtime token selection. Both
options use the declared spender and a per-approval cap in token base units.
The SDK exposes `readErc20Approval` and `approveErc20`. The standalone source
checker requires wallet declarations for approvals, including destructured calls.

The runtime advertises `sdkFeatures.appErc20Approval = 1`. Upgrade the host and
Workbench to the exact published runtime and align Workbench's shared checker
with the SDK release source. Workbench requires human approval of the specific
release before binding an app with a wildcard approval policy.

See the [Mini App wallet guide](../mini-app-wallet.md) and the
[stable release workflow](../versioning.md#stable-release-workflow).
