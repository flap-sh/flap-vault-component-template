# Vault Runtime 0.1.50

[PR #72](https://github.com/flap-sh/flap-vault-component-template/pull/72)
adds four public Binance Web3 reads to the SDK for Vault UIs and standalone
Mini Apps.

- `sdk.readBinanceTokenDynamicInfo(query)` reads current token market data.
- `sdk.searchBinanceTokens(query)` searches for tokens and can filter by chain.
- `sdk.readBinanceTokenMetadata(query)` reads token metadata and links.
- `sdk.readBinanceTokenKlines(query)` reads candlesticks for a token and interval.

Each read uses a fixed HTTPS GET endpoint. Declare its exact URL without query
parameters in `manifest.endpoints` and supply the parameters at the call site.
The SDK accepts positive integer chain IDs and sends requests without
credentials. Endpoint review records each direct call's query and source line,
including bracket calls with a statically resolvable method name.

Runtime support is reported as `sdkFeatures.binanceTokenDynamicInfo = 1` and
`sdkFeatures.binanceTokenMarketData = 1`. Update Flap hosts and Workbench to the
exact published runtime and synchronize Workbench's checker with the release
source before accepting artifacts that use the new methods.

See the [SDK guide](../sdk.md#binance-token-market-data), the
[stable release workflow](../versioning.md#stable-release-workflow), and the
[runtime compatibility contract](../runtime-module-contract.md).
