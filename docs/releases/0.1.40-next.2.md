## Included APIs

Source-package follow-up: `next.2` omits `mapCapabilities` in the ZIP marker/metadata, so Workbench rejects new map-enabled source ZIPs. The Runtime map API remains usable in local preview. The corrected packager and matching published provenance are being prepared in [next.3](0.1.40-next.3.md); use that coordinated release for new map uploads after publication.

- Shared location, motion and orientation from `next.1`: `sdkFeatures.deviceSensors=1`, declared `deviceCapabilities`, host-owned real/mock adapters, user-initiated permissions and explicit unsupported/denied/fallback states.
- Mini App subroutes: `sdkFeatures.miniAppRouting=1`, `useMiniAppRouter`, and host-only memory/browser adapters. A receiving host must provide the router; navigation does not grant chain or wallet permissions.
- Reviewed street maps: `uiFeatures.streetMap=1`, `FlapStreetMap`, and `mapCapabilities:["street-map-v1"]`. MapLibre is fixed to 6.15.0 and loads lazily; the host serves the exact packaged Worker at `/runtime-map/maplibre-6.15.0-worker.mjs`.

Map resources go directly to fixed OpenFreeMap paths. There is no generic sandbox, resource proxy, new artifact format or storage API. Map mount does not request GPS. Keep attribution and a usable store-list fallback for WebGL/Worker/resource failures. MapLibre may retain two shared Workers until page close; map removal clears its map/canvas/observers and remounts reuse the bounded pool. Phone and wallet WebView verification remains necessary.

## Testing installation

Install the exact testing version:

```sh
yarn add --exact @flapsdk/vault-runtime@0.1.40-next.2
```

Use an isolated testing branch. Hosts and Workbench need matching Runtime exports, schema/checker metadata and static Worker bytes; installing only the package does not deploy these integrations. Stable source ZIP rules remain main/latest. Private canaries are not publishable packages or submission provenance.

See [device APIs](../device-sensors.md), [routing](../mini-app-routing.md), and [street-map integration](../street-map.md).
