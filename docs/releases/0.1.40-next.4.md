## Changes

- Extend the existing `street-map-v1` map with optional `symbol`, `place`, `city`, `amount`, `expiresAt`, `respawnAt` and `kind` fields. The legacy `id/lat/lng/title` shape and `onSelectPoint(id)` callback remain valid.
- Render four rarity colors, gray cooldown/expired points without halos, city-name/count bubbles through zoom 7.2, city fly-in to zoom 12 and individual store labels above zoom 10.5. Palette overrides accept only the four known rarity keys and six-digit hex colors.
- Add separate event points/countdowns, selection and a project-owned React details slot receiving the full point and bounded display context. Legendary rarity alone remains a store; `kind:"event"` selects the event layer.
- Add a pulsing user marker, a meter-based range circle and opt-in navigation/metric scale controls. The map never requests GPS itself. Keep permission handling and explicit fallback through the shared device hooks and map state.
- Advertise `uiFeatures.streetMapPresentation=1` and immutable `STREET_MAP_PRESENTATION_V1=1`. Matching Workbench builds record the required UI export; older hosts reject unsupported enhanced artifacts before importing their module. Existing Vault UI and basic map artifacts remain compatible.

The fixed MapLibre 6.15.0 engine, unmodified same-origin Worker, OpenFreeMap dark resource policy, manifest declaration and source-package formats remain unchanged. Worker SHA-256 remains `1c69066368331aae63967ed24a9affcf962cf55fcc6d8f532a8b040f736dbcfa`. No arbitrary map URLs/styles, raw engine/Worker access, HTML popup API or new storage permission is introduced. Client distance, radius and timers are display estimates; claim authorization, quantities, records and device identity remain application responsibilities.
