# 0.1.39-next.0 — Mini App v2 动态 IPFS

[English](0.1.39-next.0.md)

本次发布目标为 npm `next`，升级前须核对 registry 元数据。正式 `latest` 保持 `0.1.37`。

- 将官方 main（`ad40bab`，正式版 0.1.37）合并到 `feat/mini-app-v2`。
- Mini App v2 与 Vault UI 共用动态 `IpfsImage`、转义纯文本组件 `IpfsText` 和有大小/并发限制的 `sdk.readIpfsText(cid, path?)`。
- 带 chainId 的 SDK 支持经声明和审核的 `sdk.readFsi(path, params?)`，仍只允许平台固定 endpoint。
- 保留共用钱包、CopyButton、Vault UI 与旧 App 兼容能力。

Vault UI 使用 `useFlapSdk()`；Mini App v2 使用 `useFlapSdk({ chainId: 56 })`。共用组件从 `@/src/ui` 导入，App 文件夹无需再安装 SDK。见 [IPFS 指南](../ipfs-content.zh-CN.md)和 [v2 快速开始](../mini-app-v2-quickstart.md)。

主站和测试 Workbench 须同步精确 runtime 版本，并部署匹配的 Workbench 校验规则；只更新 npm 依赖不够。动态内容来源仍需人工审核。源码 ZIP 继续要求官方模板来源和 PC/iPad/H5 游客/已连接六项 E2E。此次不改变打包格式、不增加依赖、不扩大交易权限。

发布前用同一个私有 canary 验证两个消费项目。浏览器使用受控内容 fixtures 检查渲染、CID 变化、文本转义及非法输入，不代表已验证真实 Pinata 可用性或项目业务交易。
