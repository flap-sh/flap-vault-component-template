# 0.1.40-next.0 — 长文本完整复制

[English](0.1.40-next.0.md)

已准备 npm `next` 发布，尚未发布。正式 `latest` 保持 `0.1.37`。

- 共用 `CopyButton` 上限从 4,096 提高至 1,048,576 个 UTF-16 代码单元（`value.length`），可完整复制 `skills.md` 等长 Markdown。
- Vault UI 与 Mini App v2 继续使用同一个组件，导入方式和参数不变；保留空格、换行，emoji 可能占多个代码单元。
- 保留真实点击、无效值拦截、等待期间去重、失败反馈及全屏下的选区复制回退；不向应用开放可编程剪贴板方法或剪贴板读取。
- 在两种 provider 下实际写入并读回长中文、emoji、Markdown 及长度边界，覆盖浏览器真实选区回退和消费项目的运行时验证。

主站和 Workbench 需固定同一精确版本，同步 Workbench 校验身份并部署。开发者更新官方 `feat/mini-app-v2` 模板，重新执行检查、E2E、打包和验证。旧产物保持兼容，不新增依赖或修改打包协议。用法见 [CopyButton](../copy-button.zh-CN.md)。
