## 本版内容

- 保留 `street-map-v1`，为点位新增可选 symbol、place、city、amount、expiresAt、respawnAt、kind。原 id／lat／lng／title 和 onSelectPoint(id) 继续兼容。
- 四级稀有度配色，冷却／过期时变灰并去除光晕；zoom ≤7.2 显示城市名／数量气泡，点击飞到 zoom 12；zoom >10.5 显示单店文字。自定义配色只接受四个稀有度键及六位 hex。
- 独立活动图层与倒计时、选中态、完整点位回调和项目自己的 React 详情槽。传奇稀有度不自动成为活动，kind:event 才进入活动图层。
- 呼吸定位点、按米绘制的范围圈，以及显式开启的导航／比例尺。地图不自行申请 GPS，沿用 SDK 用户点击申请、兼容状态和列表降级。
- 新增 uiFeatures.streetMapPresentation=1 和不可变 UI 导出 STREET_MAP_PRESENTATION_V1=1。匹配 Workbench 记录真实 required UI export，旧宿主在导入增强组件前拒绝不支持的产物；旧 Vault UI 和基础地图产物继续兼容。

MapLibre 6.15.0、未经修改的同源 Worker、OpenFreeMap dark 资源策略、manifest 声明和源码包格式均不变。Worker SHA-256 仍为 `1c69066368331aae63967ed24a9affcf962cf55fcc6d8f532a8b040f736dbcfa`。本版不开放任意地图 URL／style、原始引擎／Worker、HTML 弹窗或新存储权限。客户端距离、范围和时间只做展示；真实领取资格、数量、领取记录与设备身份仍由业务处理。
