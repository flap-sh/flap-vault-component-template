# Vault Runtime 0.1.49

[PR #70](https://github.com/flap-sh/flap-vault-component-template/pull/70)
adds standard ERC-20 reads by token address for standalone Mini Apps.

- `sdk.readErc20Metadata(token)` reads the name, symbol, and decimals on the
  chain selected with `useFlapSdk({ chainId })`. Guests can use this query.
- `sdk.readErc20Metadata(token, { decimalsOnly: true })` reads only decimals.
- `sdk.readErc20Balance(token)` reads the connected wallet's balance in base
  units. The host supplies the wallet address and no signature is needed.

These queries use the fixed SDK ABI and the host's public client. They work
before a pool exists and need no token entry in the manifest. Runtime support
is advertised by `sdkFeatures.appErc20Read = 1`. General contract calls and
fixed-Router approvals continue to use the reviewed wallet policy.

Use the exact published Runtime in Workbench and the host before delivering
artifacts that call the new methods. See the
[Mini App wallet guide](../mini-app-wallet.md#erc-20-reads-by-token-address).
