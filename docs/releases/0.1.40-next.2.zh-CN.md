# 0.1.40-next.2 测试版

[English](0.1.40-next.2.md)

按明确授权准备在 2026-10-25 发布到 npm `next`，公开发布结果将在注册表核验后补充。正式 `latest` 保持 `0.1.39`，本次不自动升级主站和 Workbench 的依赖或部署。

本包包含已有 GPS/运动/方向传感器、Mini App 子路由及轻量街道地图。Runtime 合约版本仍为 1，分别声明 `sdkFeatures.deviceSensors=1`、`sdkFeatures.miniAppRouting=1` 和 `uiFeatures.streetMap=1`。地图使用 `FlapStreetMap` 与 `mapCapabilities:["street-map-v1"]`，固定 MapLibre 6.15.0 和同版本静态 Worker；不新增沙箱、代理、产物格式或存储接口。

确认公开发布后，测试分支可精确安装：

```sh
yarn add --exact @flapsdk/vault-runtime@0.1.40-next.2
```

接收端还需同步 Runtime 导出、schema/checker 元数据、路由适配器和 `/runtime-map/maplibre-6.15.0-worker.mjs` 静态文件；只安装 npm 包不等于已完成部署。正式源码 ZIP 的 main/latest 校验保持不变，private canary 不能发布或充当提交来源。

地图直接请求固定 OpenFreeMap 资源，保留署名和可用的门店列表降级。地图挂载不自动申请 GPS。MapLibre 可保留两个页面级共享 Worker，卸载清理地图/Canvas/观察器并复用有界池，不强拆内部 dispatcher。仍需验证目标手机和钱包 WebView。

发布从与官方 `upstream/next` 完全一致的干净提交构建，通过包校验和真实 Provider 测试后，仅将核对过的 Runtime 归档发布到 `next`。发布后核对版本、`gitHead`、integrity 和下载内容，并确认正式 `latest=0.1.39` 未变化。详见[英文发布步骤](0.1.40-next.2.md)。
