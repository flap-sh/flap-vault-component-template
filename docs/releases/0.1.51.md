# Vault Runtime 0.1.51

This release adds two shared UI exports for approved artwork URLs.

- `CardImage` renders an image and can show a fallback while loading or when unavailable.
- `useCardImageBitmap(imageUrl)` decodes an image for a Three texture in packages declaring `three-r3f-v1`.

The runtime restricts downloads to the approved HTTPS image directory, enforces a response size limit, and releases image resources when they are no longer in use. Consumers can detect the capability through `uiFeatures.cardImageMedia = 1`.

See [controlled card images](../card-image-media.md) for usage and [the runtime contract](../runtime-module-contract.md) for compatibility.
